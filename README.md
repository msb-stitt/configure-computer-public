# configure-computer

The record of how each computer was set up to run the team's tools: what was installed, what
settings were changed, and the installers used.

## Which files belong to which computer

- **A name ending in `-windows` is the Windows PC's**: `.docs/*-windows.md` and
  `install-media-windows/`. The PC is `FRC-08`, Windows 11 Pro, set up from 2026-10-14 under the
  plan `.docs/2026-10-14-configureWindowsComputer.md` in `msb-stitt/ftc-claude`.
- **Every other file and folder is the Mac's**, set up from 2026-10-01.

Each computer keeps the same two logs: `install-log` for what was installed, `settings-log` for
what was changed. Installers are kept out of git in `install-media/` or `install-media-windows/`,
and each log names the file, its source and its checksum.

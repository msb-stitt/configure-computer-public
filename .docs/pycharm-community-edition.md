# PyCharm "Community Edition"

- JetBrains discontinued the separate PyCharm Community Edition. Starting with 2025.3 there is one **PyCharm** product. Its core features are free, and Pro features need a subscription or trial.
- The last true CE build is 2025.2.6.2 (2026-07-29): https://download.jetbrains.com/python/pycharm-community-2025.2.6.2-aarch64.dmg. It gets no further updates.
- Installed instead (2026-10-01): unified **PyCharm 2026.2.3**. On first launch, choose the free option. Don't start a Pro trial and don't sign in to a JetBrains account; this machine has no personal accounts.
- To find the latest download link in a script: `https://data.services.jetbrains.com/products/releases?code=PCP&latest=true&type=release`, field `.PCP[0].downloads.macM1.link`.
